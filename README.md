# Личный ИИ-ассистент в Telegram (Gemini + SQLite)

## Что умеет
- **Память**: сам сохраняет факты о тебе (профиль, предпочтения, люди, цели), обновляет устаревшие, не дублирует.
- **RAG**: на каждое сообщение ищет релевантное в памяти и документах (эмбеддинги `gemini-embedding-001`).
  Пришли боту `.txt / .md / .pdf / .csv` — он добавит файл в базу знаний.
- **Свои таблицы**: сам создаёт таблицы (`u_expenses`, `u_workouts`…) и пишет/считает через SQL.
  Работает в песочнице: системные таблицы, ATTACH, PRAGMA ему недоступны.
- **Напоминания и плановые задачи**: «каждый день в 8:00 делай мне план на день» — в 8:00 агент сам выполнит задачу.
- Голосовые и фото понимает напрямую (Gemini мультимодальный).
- Отвечает только владельцу.

## Запуск
```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```
Ключи лежат в `.env`. Впиши `OWNER_ID` (свой ID из @userinfobot) — иначе владельцем станет первый написавший.

## Модель
По умолчанию `gemini-2.5-flash` — бесплатна, умеет инструменты, голос и картинки.
Если упираешься в лимиты — поставь `GEMINI_MODEL=gemini-2.5-flash-lite` (лимиты выше, чуть глупее).
Свои лимиты смотри в Google AI Studio → Rate limits.

## Команды
/memory, /forget <id>, /tables, /docs, /deldoc <id>, /reminders, /reset

## Структура
- `bot.py` — Telegram, команды, фоновые напоминания
- `agent.py` — цикл агента (контекст + инструменты), загрузка документов
- `tools.py` — инструменты, которые вызывает модель
- `db.py` — SQLite-схема, векторный поиск, песочница SQL
- `llm.py` — Gemini API

Вся база — один файл `agent.db`. Чтобы бот работал 24/7, запусти его на VPS (systemd/docker) и делай бэкап `agent.db`.
